**Playwright** (ローカル) -- ブラウザー操作の自動化、ウェブスクレイピング、スクリーンショット取得、フォーム入力など、ウェブページとのやり取りが必要なあらゆるタスクに使用します。URL の閲覧、スクリーンショットの取得、ウェブサイトからのコンテンツ抽出、フォーム入力、ブラウザーベースのワークフローの自動化をユーザーから依頼された場合に使用してください。ウェブ操作の主要ツールです。

---

**Microsoft Learn** (リモート) -- Microsoft 公式ドキュメントの検索と取得を行います。Azure サービス、Microsoft 365、.NET、PowerShell、Windows、Visual Studio、その他の Microsoft 関連技術について質問された場合に使用してください。Microsoft 関連の質問では、結果が公式かつ最新で構造化されているため、一般的なウェブ検索よりもこちらを優先してください。キーワード検索とページ全文取得に対応しています。

---

**Azure MCP Server** (ローカル) -- Azure クラウドリソースを直接管理します。Azure リソース (リソースグループ、ストレージアカウント、VM、App Services、Cosmos DB、Key Vault など) の一覧表示、作成、更新、削除、Azure Resource Graph のクエリ実行、デプロイ管理、Azure サブスクリプションの検査をユーザーから依頼された場合に使用してください。ローカルの `az login` セッションを通じて認証します。利用可能な場合は、シェルの `az` コマンドよりもこちらを優先してください。AI が構造化されたツール呼び出しで Azure にアクセスできるようになります。

---

**GitHub MCP Server** (ローカル) -- GitHub API の完全な統合機能を提供します。リポジトリ、Issue、プルリクエスト、コミット、ブランチ、リリース、GitHub Actions ワークフロー、コード検索など、GitHub に関する操作について質問された場合に使用してください。`gh` CLI や生の API 呼び出しよりもこちらを優先してください。リポジトリの一覧表示、Issue の作成、プルリクエストのレビュー、コード検索、ラベル管理などのための構造化ツールが公開されています。
